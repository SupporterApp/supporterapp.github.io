<h1>My events</h1>
<p>In this section you'll find all the events you have pending to complete and those that have already been counted. It's your personal participation history, with the score you've earned on each one.</p>

<hr />

<h2>📌 Pending events</h2>
<p>Here you'll see the events you haven't completed yet, or that you've taken part in but the system hasn't closed yet. Each event is grouped by the match it belongs to.</p>
<p>The types of events you may find are:</p>
<ul>
<li>🎵 <strong>Songs:</strong> play a song for a set amount of time.</li>
<li>❓ <strong>Questions:</strong> answer the match questions correctly.</li>
<li>🏆 <strong>Match MVP:</strong> vote for the most valuable player of the match.</li>
<li>⚽ <strong>Matches:</strong> the matches you've confirmed attendance for.</li>
</ul>

<h2>✅ Counted events</h2>
<p>Once an event <strong>has finished and the system has calculated its result</strong>, it will appear in this section with:</p>
<ul>
<li>The <strong>points earned</strong>.</li>
<li>A <strong>green check mark</strong> confirming the result has been processed.</li>
</ul>
<p>This means an event you've completed may take a while to appear here: first the participation period must end, and then the system must calculate the results.</p>

<h2>🔍 Viewing the results</h2>
<p>Counted events are not just a points log: you can also check <strong>how it went</strong>. Cards that can be opened show a <strong>› arrow</strong> on the right; tap them to see the details.</p>
<ul>
<li><strong>Questions:</strong> you will see each question with <strong>your answer</strong> and the <strong>correct answer</strong>, marked with a green tick if you got it right or a red cross if you did not. If you left a question unanswered it appears as <em>No answer</em>, and the question's <strong>source</strong> is shown when available.</li>
<li><strong>Match MVP:</strong> you will see <strong>the most voted</strong> players with their vote count, and <strong>your vote</strong> highlighted in the list. If your vote did not make the top options, it is still shown in a separate card.</li>
<li><strong>Matches:</strong> the arrow opens the match information. If the match has already finished you will see the <strong>statistics</strong>; if it is still being played, the live information.</li>
</ul>
<p>If the event has been counted but the detail is not published yet, you will see a message saying there are <strong>no results yet</strong>. Try again later: the system publishes them once it has finished calculating.</p>

<h2>🏆 How the match MVP works</h2>
<p>The MVP is the star event of the match: it's about voting for the <strong>most valuable player</strong> among everyone who took part in the game.</p>
<ul>
<li>When you enter the MVP, your attendance is registered automatically.</li>
<li>You'll see the <strong>voting window</strong> with the start and end times. Make sure you vote within this interval.</li>
<li><strong>While the voting window is open, you can re-enter and change your vote</strong> as many times as you like.</li>
<li>Once you submit your vote, the MVP <strong>won't disappear from pending</strong> nor move to counted immediately: this will only happen <strong>when the event closes and the system calculates the results</strong>.</li>
<li>When that happens, the MVP will appear in the counted events section with the corresponding points.</li>
</ul>

<h2>⚽ Access the match information</h2>
<p>Events of type <strong>MATCH</strong> have a link to the match information (with the open-in-new-window icon). Click it to see the lineups, the statistics and the score.</p>
<p>Already counted matches also have this link, in case you want to check the match information again.</p>

<h2>🔄 Refresh the list</h2>
<p>You can refresh the list at any time by swiping the screen down (pull-to-refresh gesture). This will reload the events and reflect the most recent changes.</p>

<h2>💡 Tips</h2>
<ul>
<li>If an event has a time limit, make sure you take part within the indicated window.</li>
<li>The MVP usually appears at the end of the match: stay tuned to notifications.</li>
<li>If you've voted for the MVP but don't see it in counted yet, don't worry: it's pending the system calculating the results.</li>
</ul>
