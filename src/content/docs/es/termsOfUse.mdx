<li>Copiar, modificar o distribuir el código o contenido de la Aplicación sin autorización.</li>
<li>Utilizar la Aplicación para enviar spam o contenido malicioso.</li>

<h2>4. Funcionalidad de geolocalización</h2>
<p>La función de verificación de asistencia requiere acceso a la ubicación GPS del usuario. Esta función se activa solo con el consentimiento explícito del usuario. La ubicación solo se compara con las coordenadas del estadio para verificar la asistencia; <strong>no se almacena un historial de movimientos</strong> del usuario.</p>

<p>La Aplicación utiliza Firebase Cloud Messaging (FCM) para enviar notificaciones push relacionadas con eventos, recordatorios o cambios de última hora. El usuario puede desactivar estas notificaciones desde la configuración de su dispositivo en cualquier momento.</p>
