<h2>2. Datos que recopilamos</h2>
<p>Recopilamos los siguientes datos personales:</p>
<ul>
<li><strong>Alias:</strong> Un nombre de usuario elegido libremente por el usuario.</li>
<li><strong>Identificador interno:</strong> Un código aleatorio generado por el sistema para identificar al usuario de manera única.</li>
<li><strong>Datos de geolocalización:</strong> Coordenadas GPS del usuario (solo cuando se utiliza la función de verificación de asistencia al estadio).</li>
<li><strong>Datos de uso:</strong> Estadísticas anónimas de navegación e interacción con la aplicación (mediante Firebase Analytics).</li>
<li><strong>Token de notificación:</strong> Identificador para el envío de notificaciones push (FCM).</li>
</ul>

<p>En cuanto a los datos de uso, Firebase Analytics recopila automáticamente información técnica del dispositivo (modelo, sistema operativo, idioma), datos de interacción con la aplicación (pantallas visitadas, funciones utilizadas y participación en eventos) e identificadores técnicos aleatorios. Nunca se envían a Analytics datos que permitan identificarte directamente (ni tu alias, ni tu correo electrónico).</p>

<h2>3. Finalidades del tratamiento</h2>
<p>Los datos recopilados se tratan con las siguientes finalidades:</p>
<ul>
<li>Gestionar el registro y la identificación del usuario dentro de la aplicación.</li>
<li>Verificar la asistencia a eventos deportivos comparando la ubicación del usuario con las coordenadas del estadio (utilizando un servicio de cálculo geoespacial).</li>
<li>Enviar notificaciones push relacionadas con el evento (recordatorios, cambios de horario, etc.).</li>
<li>Analizar el uso de la aplicación para mejorar la experiencia del usuario.</li>
</ul>

<h2>4. Base legal</h2>
<p>La base legal para el tratamiento de los datos es el <strong>consentimiento expreso</strong> del usuario (artículo 6.1.a del RGPD), que se manifiesta en el momento del registro y en la aceptación de esta política.</p>
<p>Para la geolocalización, se solicita un consentimiento adicional y específico antes de activar la función.</p>

<p>El consentimiento para la analítica de uso (Firebase Analytics) se presta en el momento del registro, al aceptar esta política, y cubre la recopilación de los datos de uso descritos en el apartado 2. Puedes retirarlo en cualquier momento contactando con nosotros en <a href={`mailto:${email}`}>{email}</a>; al retirarlo, la aplicación dejará de enviar datos de uso.</p>

<h2>5. Encargados del tratamiento (proveedores)</h2>
<p>El responsable utiliza los servicios de las siguientes empresas para el tratamiento de datos:</p>
<ul>
<li><strong>Google LLC (Firebase):</strong> Autenticación, base de datos Firestore, Remote Config, FCM (notificaciones) y Analytics. Información en: <a href="https://firebase.google.com/privacy" target="_blank">https://firebase.google.com/privacy</a></li>
<li><strong>MongoDB, Inc. (Atlas):</strong> Base de datos geoespacial para la comprobación de ubicaciones. Información en: <a href="https://www.mongodb.com/legal/privacy-policy" target="_blank">https://www.mongodb.com/legal/privacy-policy</a></li>
</ul>

<h2>6. Transferencias internacionales</h2>
<p>Los datos almacenados en Firebase se encuentran, principalmente, en servidores dentro de la Unión Europea. Sin embargo, Google LLC es una empresa con sede en los Estados Unidos, por lo que existe una transferencia internacional de datos.</p>
<p>Esta transferencia está cubierta por las <strong>Cláusulas Contractuales Tipo (SCC)</strong> aprobadas por la Comisión Europea, que garantizan un nivel de protección adecuado. El usuario puede solicitar más información sobre estas garantías en la dirección de correo indicada.</p>

<h2>7. Conservación de los datos</h2>
<p>Los datos se conservarán mientras el usuario mantenga la cuenta activa. Pasados <strong>2 años</strong> de inactividad, el responsable podrá proceder a la eliminación de los datos personales, a menos que el usuario solicite la baja antes.</p>

<h2>8. Derechos del usuario</h2>
<p>El usuario tiene derecho a ejercer los siguientes derechos en cualquier momento, enviando un escrito a {email}:</p>
<ul>
<li><strong>Acceso:</strong> Saber qué datos tenemos sobre ti.</li>
<li><strong>Rectificación:</strong> Modificar datos inexactos.</li>
<li><strong>Supresión (derecho al olvido):</strong> Eliminar tus datos.</li>
<li><strong>Limitación del tratamiento:</strong> Restringir el uso de tus datos.</li>
<li><strong>Oposición:</strong> Oponerte al tratamiento para fines concretos.</li>
<li><strong>Portabilidad:</strong> Recibir los datos en un formato estructurado y legible.</li>
</ul>
<p>También tienes derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD) si consideras que no hemos tratado correctamente tus datos.</p>
<p>Si quieres eliminar la cuenta, tienes los pasos detallados en <a href="/es/legal/deleteAccount">Eliminar la cuenta</a>.</p>
